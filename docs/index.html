EduShell OS

EduShell is a mini operating system shell written in C. It shows how an OS reads a command, parses it, and runs it.

  • Command parsing and dispatch
  • Built-in commands
  • Process execution
  • Modular C code: include/ and src/

Open the Terminal on the dock and type help.

Command Guide

Commands

  • help list commands
  • ls list files
  • cat file show a file
  • touch file create a file
  • rm file delete a file
  • echo text print text
  • neofetch system info
  • history date whoami clear
  • sleep 30 or count 20 run a job in the foreground
  • sleep 30 & run a job in the background
  • jobs list jobs, ps list processes
  • fg %1 bring a job to the foreground
  • bg %1 resume a stopped job in the background
  • kill %1 terminate a job
  • Ctrl+Z stop job, Ctrl+C kill job (or use the ^Z / ^C buttons)

Edit this list to match the commands in your real shell.
